
# FitFlow AI – AI-Powered Fitness Assistant

## Project Overview
FitFlow AI is an AI-powered fitness assistant developed as part of my Diploma in Applied AI and Analytics at Republic Polytechnic.

The project provides personalised workout and meal recommendations based on users' fitness goals, activity levels and preferences.

## Technologies Used
- n8n – AI workflow automation
- Telegram Bot – Chatbot interface
- OpenRouter – AI model integration
- Google Sheets – Fitness recommendation database
- Web Technologies – Website chatbot interface

## Key Features
- Generates personalised 7-day workout and meal plans.
- Supports chatbot interactions through Telegram and a website.
- Uses Google Sheets to retrieve fitness recommendations.
- Uses AI agents and workflow automation to process user requests.
- Maintains conversation context using n8n Simple Memory.

## My Contributions
- Developed and configured the n8n AI automation workflows.
- Integrated the AI chatbot with Telegram, Google Sheets and the website.
- Implemented conditional routing for different chatbot platforms.
- Tested and troubleshot workflow and integration issues.
